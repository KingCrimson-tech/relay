# Relay

A small topic-based publish/subscribe broker built with Node.js, Fastify,
WebSockets, and PostgreSQL.

This repository contains a build-it-yourself tutorial series that implements Relay
from an empty directory, one phase at a time.

- **[Build Yourself a Relay](docs/README.md)** — the full series, with concepts,
  code, and commands.
- **[plan.md](plan.md)** — the original phase-by-phase plan.

The series is documentation only. Following it produces the working project in a
separate directory; this repository does not contain the implementation.
